### Import Resolution

Python imports configured via `sitecustomize.py`:

```python
# Created in: ~/.conda/envs/cosyvoice/lib/python3.8/site-packages/
import sys
sys.path.insert(0, '/path/to/tts_service/CosyVoice')
sys.path.insert(0, '/path/to/tts_service/CosyVoice/third_party/Matcha-TTS')
```

This allows proper imports:
```python
from cosyvoice.cli.cosyvoice import CosyVoice  # ✅ Works
from cosyvoice.utils.file_utils import load_wav  # ✅ Works
```

### Model Loading Flow

```
1. Check local path: pretrained_models/CosyVoice-300M-SFT
   ├─ Exists? → Load directly
   └─ Missing? → Download from ModelScope

2. Initialize: CosyVoice(model_path)
   ├─ Loads model files
   ├─ Initializes tokenizer
   └─ Moves to device (CPU/CUDA)

3. Get speakers: model.list_available_spks()
   └─ Returns: ['中文女', '中文男', ...]

4. Synthesize: model.inference_sft(text, speaker, stream=True)
   └─ Yields audio chunks
```

### API Call Examples

**Official way (now used):**
```python
from cosyvoice.cli.cosyvoice import CosyVoice

# Load model
model = CosyVoice('pretrained_models/CosyVoice-300M-SFT')

# Get speakers
speakers = model.list_available_spks()
# Returns: ['中文女', '中文男', '日语男', ...]

# Non-streaming
for chunk in model.inference_sft(text, '中文女', stream=False):
    audio = chunk['tts_speech']  # Tensor or numpy array

# Streaming
for chunk in model.inference_sft(text, '中文女', stream=True):
    audio = chunk['tts_speech']
    # Process/stream audio immediately
```

## 🐛 Common Issues & Solutions

### Issue: "conda: command not found"
**Solution:** Install Conda first
```bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
```

### Issue: "CosyVoice import fails"
**Solution:** Re-run setup
```bash
./setup.sh
```

### Issue: "Model not found"
**Solution:** Pre-download model
```bash
conda activate cosyvoice
cd CosyVoice
python -c "from modelscope import snapshot_download; snapshot_download('iic/CosyVoice-300M-SFT', local_dir='../pretrained_models/CosyVoice-300M-SFT')"
```
